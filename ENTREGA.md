## O que foi implementado

- Tabela `eventos` criada no Supabase com os campos pedidos.
- Três eventos iniciais cadastrados.
- API Node.js com Express publicada no Render.
- Rotas `GET /api/eventos`, `POST /api/eventos` e `GET /health`.
- Frontend com cadastro e listagem publicado na Vercel.
- CORS configurado para a URL da aplicação.

## Conferência

A aplicação foi acessada em produção e a listagem exibiu os três eventos carregados do Supabase. O cadastro usa o formulário da página e envia os dados para a API do Render.
